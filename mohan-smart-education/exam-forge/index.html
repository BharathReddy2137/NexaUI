ExamForge is an interactive exam preparation interface with six searchable practice sets, timed MCQ sessions, question navigation, answer selection, scoring, explanations, result review, and JSON export. All question banks and dashboard metrics are sample content. Results are calculated in the browser; production use needs persistence and a trusted backend.

Sample data is provided for the hackathon demo. Explore the interactive sections to see the workflow.
